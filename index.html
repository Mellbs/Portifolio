Projetos

Projeto 1: Site de Certificado Digital

Desenvolvimento de um site de certificado digital utilizando HTML, CSS e JavaScript para facilitar o agendamento de criação/renovação de certificados. O usuário preenche os dados e envia direto para o whatsapp da empresa com uma mensagem pré-definida. O site é responsivo e possui um design moderno e atraente.


Projeto 2: Site de vendas Mini Caseirinho

Desenvolvimento de um site de vendas para uma loja de produtos caseiros utilizando HTML, CSS e JavaScript. O site permite a navegação pelos produtos, adição ao carrinho e finalização da compra. O usuário escolhe o. produto, escolhe o meio de pagamento e de entrega e envia direto para o whatsapp do vendedor com uma mensagem pré-definida. O design é moderno e responsivo, proporcionando uma boa experiência ao usuário.
